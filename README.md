# SimLegacy 2.4 — семейные фотоархивы и память о симах

Обновление исходного проекта SimLegacy. Сохраняет все существующие возможности: создание династий, анимированный мастер сима, карточки, родственные и романтические отношения, линии, drag & drop карточек, масштабирование колёсиком, поиск, экспорт/импорт JSON. Это исходный проект для Vercel, **он не опубликован автоматически**.

## Что нового

### Личный фотоальбом персонажа

Откройте карточку сима → вкладка **«Фото»** → **«Добавить фотографии»**. Можно выбрать сразу несколько JPG/PNG/WEBP, вписать подпись под каждым снимком, удалить снимок, раскрыть на весь экран, листать стрелками на клавиатуре и сделать снимок основным портретом. После загрузки и редактирования нажмите **«Сохранить изменения»** в карточке персонажа.

### Общий фотоальбом династии

Откройте древо → **«Фото династии»** в верхней панели → загрузите фото → при желании назначьте один снимок обложкой → **«Сохранить фотоальбом»**. Альбом доступен для просмотра в публичном дереве; опубликованная галерея показывает количество фото. Династии без фотоальбома не затрагиваются.

### Статус «Жив» / «Умер»

В редактировании сима, вкладка **«Анкета»**, есть переключатель статуса. Статус не привязан к возрасту: молодой взрослый тоже может быть отмечен умершим. Для умершего можно выбрать причину смерти, написать подробности и указать дату смерти во вкладке «История». На древе такой персонаж отображается в сероватой гамме с небольшим SVG-надгробием, а при открытии карточки появляется мемориальный блок.

Старые карточки с жизненным этапом `Умерший` сохраняют статус умершего автоматически. Связи родственников при изменении статуса не удаляются. Статус не влияет на поколение.

### Дополнение по примерам: фон древа

Откройте **«Настроить»** → выберите обложку династии → включите **«Кинематографичный фон древа»** → сохраните. Фотография станет размытым фоном за персонажами, аналогично визуальному эффекту из референсов. По умолчанию выключено, существующие деревья не меняются.

## Как обновить Vercel через GitHub

1. **Перед обновлением экспортируйте резервную копию JSON** из текущего дерева.
2. Распакуйте ZIP, откройте папку **`simlegacy-v2`**.
3. Замените содержимое существующего репозитория `impislat/simlegacy-v2` файлами из этой папки, сохранив структуру `src/`, `supabase/`, `tests/` и файлы в корне.
4. Нажмите **Commit changes**. Vercel автоматически запустит новую сборку (если репозиторий подключён).
5. Дождитесь статуса **Ready** и проверьте загрузку фото, сохранение и повторное открытие страницы.

**Важно:** простая замена только `main.jsx` и `style.css` на этот раз недостаточна. Появились новые файлы: `src/PhotoAlbum.jsx`, `src/photo-album.css`, `src/photoAlbum.js`, `src/simStatus.js`. Также обновлён `src/backend.js`.

## Без Supabase

Сайт работает в локальном режиме без сервера. Галереи и статусы персонажей сохраняются внутри JSON дерева в localStorage этого браузера. Для локальной загрузки фото уменьшаются и сжимаются, но **вместимость браузера ограничена** (на практике несколько мегабайт). Лимит интерфейса — 12 фото на персонажа и 12 на династию, однако предел браузерного хранилища может наступить раньше. Регулярно экспортируйте JSON. При очистке данных браузера фото и деревья можно потерять.

## С Supabase

Если облако уже подключено, **обязательно повторно выполните `supabase/schema.sql` в Supabase SQL Editor**, чтобы добавить новые столбцы `gallery` (JSONB) и `background_enabled` к существующим деревьям. Запрос использует `ADD COLUMN IF NOT EXISTS` и сохраняет прежние данные. После выполнения повторно опубликуйте исходники Vercel.

Фото персонажей хранятся в `people[].gallery`, фото династии — в `trees.gallery`. При подключённом Supabase изображения загружаются в bucket `sim-images`, а в JSON сохраняются публичные URL; это подходит для публичной галереи, но требует настроенных RLS и Storage policies из `schema.sql`.
