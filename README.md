# SimLegacy v2

Русскоязычный сайт для семейных деревьев The Sims 4. Дизайн оригинальный, вдохновлён UX сервисов построения династий, без копирования их графических материалов.

## Разработка

```bash
npm install
npm run dev
```

Откройте адрес Vite в браузере.

## Настоящие аккаунты, общая галерея и облачные фотографии

1. Создайте проект на Supabase.
2. Откройте **SQL Editor** и выполните `supabase/schema.sql`.
3. Скопируйте `.env.example` в `.env` и заполните `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` из Supabase Project Settings → API. Это публичный ключ (`anon` / publishable), **НЕ** `service_role`.
4. В Supabase Authentication → URL Configuration укажите свой адрес сайта (Site URL и Redirect URLs). Включите Email/Password в Authentication → Providers.
5. Запустите `npm run dev` или задеплойте собранный сайт (`npm run build`, папка `dist`) на Cloudflare Pages, Netlify, Vercel.

Без Supabase сайт работает в локальном демо-режиме с сохранением дерева в браузере. В таком режиме нет настоящей регистрации, серверной галереи, синхронизации или публичных ссылок. Не представляйте демо-режим как облачный сервис.

## Возможности

- Собственные династии, несколько деревьев
- Персонажи с фотографиями (JPG/PNG/WEBP), биографиями, поколениями, жизненными этапами
- Связи родителей, детей и партнёров; визуальные линии дерева
- Масштабирование и панорамирование, поиск и фильтр поколений
- Редактор обложки и описания дерева
- Регистрация/вход через Supabase Auth; хранение деревьев в PostgreSQL с RLS
- Галерея с реальными публичными династиями и просмотром по прямой ссылке
- Импорт и экспорт JSON

## Перед масштабным публичным запуском

Добавьте защиту от спама и жалобы на публикации, модерацию изображений, удаление пользовательского аккаунта с данными, политику конфиденциальности и условия использования, мониторинг и резервные копии. Локальные изображения в демо-режиме могут упереться в лимиты браузера — для реального сайта необходим серверный storage.
